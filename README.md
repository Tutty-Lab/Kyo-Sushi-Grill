# Kyo sushi & grill

Source từ Kimi-Sushi-Bar; repo độc lập, không mang dữ liệu/lịch sử cũ.

- Ledergasse 22, 73525 Schwäbisch Gmünd.
- Mỗi ngày và ngày lễ: 10–14h, 16:30–22h. Chưa có ngày nghỉ nên mặc định mở cả tuần.
- Bếp: 1,2,3,4,5. Bồi: 16,19,18,6,10,14,15,17. Vollzeit 160h/tháng.
- Tài xế: 8,9,11,13. Minijob ưu tiên 17–22h, cho phép ban ngày.
- Định mức tài xế tạm 43h/tháng; cần chỉnh theo hợp đồng thực tế. Chưa có tên/lương.
- Cao điểm 18–21h; thứ 6–7 hệ số 1,5.
- Mức tối thiểu tạm: 1 bếp + 1 bồi trong giờ mở; tài xế không thay thế.
- Không thêm chủ hoặc số 7,12. Ngày lễ Baden-Württemberg.
- Lưu local riêng. Supabase cần cấu hình mới qua biến môi trường.

```sh
npm ci
npm run dev
npm test
npm run build
```
