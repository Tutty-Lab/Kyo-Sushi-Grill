# Kyo sushi & grill

Source từ Kimi-Sushi-Bar; repo độc lập, không mang dữ liệu/lịch sử cũ.

- Ledergasse 22, 73525 Schwäbisch Gmünd.
- Mỗi ngày và ngày lễ: 10–14h, 16:30–22h. Chưa có ngày nghỉ nên mặc định mở cả tuần.
- Bếp: 1,2,3,4,5. Bồi: 16,19,18,6,10,14,15,17. Định mức từng người theo bảng tháng 10.
- Tài xế: 8,9,11,13. Minijob ưu tiên 17–22h, cho phép ban ngày.
- Định mức tài xế theo bảng: 8 = 28h; 9 = 15h; 11 = 25h; 13 = 20h. Tổng 88h, không đủ phủ 155h buổi tối tháng 10.
- Tổng định mức 17 người: 1.228h/tháng (bếp 670h, bồi 470h, tài xế 88h).
- Cao điểm 18–21h; thứ 6–7 hệ số 1,5.
- Mức tối thiểu tạm: 1 bếp + 1 bồi trong giờ mở; tài xế không thay thế. Tài xế phân bổ theo định mức, ưu tiên 17–22h.
- Không thêm chủ hoặc số 7,12. Ngày lễ Baden-Württemberg.
- Lưu local riêng. Supabase cần cấu hình mới qua biến môi trường.

```sh
npm ci
npm run dev
npm test
npm run build
```
